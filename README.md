## What I work on

I design and deploy AI systems for environments where latency, privacy, hardware constraints, or cloud dependence matter.

- **Edge AI:** efficient inference on CPUs, mobile devices, and constrained hardware
- **On-prem AI:** private model serving, retrieval, and data pipelines
- **Production ML:** model optimization, deployment, evaluation, and observability
- **Agent systems:** developer tooling and evidence-driven evaluation

## Pinned projects

- **[DEIMKit](https://github.com/dnth/DEIMKit):** a practical Python toolkit for training, inference, ONNX export, and deployment with the DEIM object detector
- **[tracegrad](https://github.com/dnth/tracegrad):** evidence-gated system-prompt optimization using traces and LLM-judge results
- **[firstmate](https://github.com/dnth/firstmate):** an agent distro that orchestrates coding-agent crews through isolated worktrees and supervised delivery
- **[Supercharge Your PyTorch Image Models](https://github.com/dnth/supercharge-your-pytorch-image-models-blogpost):** benchmark-driven inference optimization with ONNX Runtime and TensorRT
- **[YOLOv5 with DeepSparse](https://github.com/dnth/yolov5-deepsparse-blogpost):** run object detection at more than 180 FPS on a four-core CPU
- **[PyTorch at the Edge](https://github.com/dnth/timm-flutter-pytorch-lite-blogpost):** deploy more than 900 TIMM models on Android with TorchScript and Flutter
